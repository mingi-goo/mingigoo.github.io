# 칭다오 가족여행 안내 앱

2026년 10월 23일(금)~25일(일) 칭다오 2박 3일 가족여행용 웹앱입니다.
빌드 과정이 없는 정적 파일이라 GitHub Pages에 올리면 바로 열립니다.

## 파일 구성

| 파일 | 하는 일 | 고칠 일 |
| --- | --- | --- |
| `data.js` | 일정, 장소, 메뉴, 문장 등 **모든 콘텐츠** | 여기만 고치면 됩니다 |
| `index.html`, `app.js`, `styles.css` | 화면 뼈대, 동작, 디자인 | 거의 없음 |
| `sw.js` | 오프라인 저장 | 드물게 `VERSION` 숫자만 |
| `manifest.webmanifest`, `icons/` | 홈 화면 추가용 이름과 아이콘 | 없음 |
| `images/` | 사진을 넣을 폴더 (지금은 비어 있음) | 사진 추가 시 |

## 콘텐츠 고치는 방법 (GitHub 웹에서)

1. 저장소에서 `data.js`를 누르고 오른쪽 위 연필 아이콘(Edit)을 누릅니다.
2. 아래 표에서 고칠 부분을 찾아 글자만 바꿉니다. 따옴표 `"`와 쉼표 `,`는 지우지 마세요.
3. 아래 **Commit changes** 버튼을 누릅니다. 1~2분 뒤 사이트에 반영됩니다.
4. 가족 휴대폰은 인터넷이 될 때 앱을 열면 새 내용으로 저절로 바뀝니다(한 번 깜빡이며 새로고침).

| 바꾸고 싶은 것 | `data.js`에서 찾을 곳 |
| --- | --- |
| 일정 시각·내용 | `days:` 아래 1일차/2일차/3일차의 `items` |
| 집합 장소 | 일정 항목의 `gather: "숙소 앞"` (집합인 일정에만 붙임) |
| 인천공항 집합 시각·장소 | 맨 위 `departure:`의 `meetTime`, `meetPlace` |
| 장소 설명, 중국어 이름 | `places:` 아래 각 장소의 `desc`, `zh` |
| 토요일 저녁 식당 | `places:`에서 `id: "satdinner"` 의 `name`, `zh`, `desc`, `menu` |
| 식당 추천 메뉴 | 각 장소의 `menu: [ ... ]` — `{ zh: "중국어", ko: "한국어 이름", desc: "설명", image: "" }`. 목록 제목은 `menuTitle` |
| 길 잃었을 때 화면 | `lost:` (안내 문구, 주소, 택시 문장, 위챗 도움 요청 `help`, 연락처) |
| 간단한 중국어 | `phrases:` — `{ ko: "뜻", sound: "한글 발음", zh: "中文" }` |
| 준비물 / 알아둘 점 | `checklist:` / `tips:` |
| 야시장 먹거리 | 타이동 야시장(`id: "taidong"`)의 `menu`를 고치면 더보기 탭에도 같이 바뀝니다 |
| 중국 이야기 | `stories:` — `{ title: "제목", body: "내용" }` |
| 여행 후 인사말 | `farewell:` |

### 예시

식당을 바꿀 때 (예: 토요일 저녁):

```js
{
  id: "satdinner",
  name: "○○ 식당",          // 한국어 이름
  zh: "○○饭店",             // 중국어 이름 (크게 보기·길찾기에 쓰임)
  type: "식당",
  desc: "한국어 설명 2~3문장.",
  image: "",
  menu: [
    { zh: "菜名", ko: "한국어 이름", desc: "설명", image: "" }
  ]
},
```

그리고 `days:`의 2일차 저녁 일정 제목도 바꿔 주세요. `place: "satdinner"`는 그대로 둡니다.

### 지켜야 할 것

- 모르는 값은 `"미정"`으로 둡니다. 화면에 흐리게 "미정"이라고 보입니다.
- 시각은 중국 현지 시간, `"09:05"`처럼 두 자리로 씁니다. 한국 시간이면 `tz: "KST"`를 붙입니다.
- 끝 시각이 있으면 `end: "10:05"`를 붙입니다. 시각이 없으면 `time: null, timeLabel: "귀가 전"`처럼 씁니다.
- 이 저장소와 사이트는 **공개**입니다. 예약번호, 차량 번호, 기사 이름, 가족 실명·전화번호, 여권 정보, 결제 금액은 넣지 마세요.

## 사진 넣기 (선택)

1. `images` 폴더에 사진을 올립니다 (Add file → Upload files). 가로 1200px 이하 jpg를 권장합니다.
2. `data.js`에서 해당 장소나 메뉴의 `image: ""`를 `image: "images/zhanqiao.jpg"`처럼 바꿉니다.
3. 사진을 바꿀 때는 **파일 이름을 새로** 지어 주세요 (같은 이름이면 휴대폰에 예전 사진이 남을 수 있습니다).

## 반영이 안 될 때

`sw.js` 맨 위의 `var VERSION = 1;` 숫자를 하나 올려서(2, 3, …) 저장하면, 다음에 앱을 열 때 모든 파일을 새로 받습니다.

## 미리 보기 (테스트)

주소 뒤에 `?now=` 를 붙이면 그 시각(중국 시간) 기준으로 "지금" 화면을 볼 수 있습니다. 화면 맨 위에 "미리보기" 띠가 나옵니다.

- `…/?now=2026-10-23T16:30` — 1일차 공항 도착
- `…/?now=2026-10-24T14:00` — 2일차 점심
- `…/?now=2026-10-24T10:08` — 장소 사이 이동 중
- `…/?now=2026-10-25T13:30` — 여행 끝
- `…/?now=2026-10-10T12:00` — 여행 전

## 동작 메모

- 시간은 휴대폰 설정과 관계없이 중국 시간(UTC+8)으로 계산합니다.
- 외부 CDN, 외부 폰트, 지도 API를 쓰지 않습니다. "길찾기"만 고덕지도(Amap) 웹 링크를 엽니다(인터넷 필요).
- 한 번 연 뒤에는 비행기 모드에서도 모든 화면이 열립니다.
- 검색 엔진 색인 제외(noindex)가 설정되어 있습니다.
